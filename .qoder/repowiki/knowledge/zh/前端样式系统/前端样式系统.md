## 前端样式系统

Clawith 平台采用自定义设计系统，结合了暗色主题和明色主题，主要通过 CSS 自定义属性（CSS Variables）实现主题切换。系统包含两个主要的样式文件：`index.css` 和 `atlas.css`。

### 核心样式系统

**主样式文件 (`src/index.css`)**：
- 定义了基于 Linear 风格的深色主题设计系统
- 使用 CSS 自定义属性定义颜色、间距、字体、边框半径等设计令牌
- 支持深色和浅色主题切换，通过 `[data-theme="dark"]` 和 `[data-theme="light"]` 选择器实现
- 包含完整的布局系统、表单元素样式、按钮样式等

**Atlas 设计系统 (`src/styles/atlas.css`)**：
- 专门为入职流程屏幕设计的独立设计系统
- 使用纸张/夜晚主题（Paper/Night design system）
- 所有样式都限定在 `.atlas-page` 作用域内，不影响其他页面
- 包含独特的字体族（Newsreader、IBM Plex Sans、IBM Plex Mono）
- 提供 Atlas 特有的组件样式如按钮、输入框、标题等

### 主题管理

**主题切换机制**：
- 通过 `data-theme` 属性控制主题切换
- 深色主题：`--bg-primary: #0a0a0f`, `--text-primary: #e1e1e8`
- 浅色主题：`--bg-primary: #f8f8f7`, `--text-primary: #1a1a22`

**动态主题色**：
- 在 `src/utils/theme.ts` 中实现了动态主题色工具
- 允许用户从预设颜色中选择主题色（靛蓝、青绿、蓝色等）
- 通过 `applyAccentColor` 函数动态生成主题色变体
- 主题色持久化存储在 localStorage 中

### 样式架构

**CSS 架构**：
- 采用 BEM 命名约定的类名结构
- 大量使用 CSS Grid 和 Flexbox 进行布局
- 通过 CSS 自定义属性实现设计系统的可维护性
- 包含响应式设计考虑

**组件样式**：
- 组件样式直接嵌入到对应的 CSS 文件中
- 没有使用 CSS-in-JS 或预处理器框架
- 通过传统的 CSS 类名在 React 组件中应用样式

### 设计规范

**颜色系统**：
- 深色主题为主，包含多个层次的背景色（primary、secondary、tertiary）
- 语义化颜色（success、warning、error、info）
- 状态颜色（running、idle、stopped、error）

**排版系统**：
- 主要字体：Inter，等宽字体：JetBrains Mono
- 定义了从小到超大（xs 到 3xl）的文本层级
- Atlas 系统使用不同的字体族（Newsreader 衬线字体）

**间距与圆角**：
- 间距系统：从 4px 到 48px 的递增空间单位
- 圆角系统：sm（4px）、md（6px）、lg（8px）、xl（12px）、full（9999px）

该样式系统体现了现代 Web 应用的设计趋势，注重主题切换能力、可访问性和设计一致性。
